# 新世代 STC 智慧排課系統 (STC Smart Timetable Web App)

相容傳統 STC (v3.77) 國中小排課系統格式之現代化 Web 智慧排課應用程式。

## 🌟 系統特色
- ⚡ **CSP 多核心智慧排課引擎**：150ms 內完成全校 30+ 班級與 50+ 教師無衝突排課。
- 🖱️ **HTML5 直覺拖拉微調**：即時衝堂警示與專科教室/教師重疊提醒。
- 🚫 **教師不排課時段 Matrix GUI**：直覺點選禁止排課時段。
- 📊 **四維度課表檢視**：全校總表、班級課表、教師課表、專科教室課表。
- 📁 **STC 舊檔相容與 CSV 匯出**：相容既存 STC 檔案並支援匯出 UTF-8 CSV 與列印模式。
